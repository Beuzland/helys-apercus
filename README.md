# Aperçus des visuels Helys

Brouillons des visuels proposés par l'agent de croissance de Helys, pour que Richard les voie sur
son téléphone pendant le point du matin. **Rien ici n'est publié ni validé.**

Un dossier par jour (`AAAA-MM-JJ/`). Les sources et l'historique sont dans le dépôt privé de
l'agent ; ce dépôt n'est qu'une vitrine, écrite par la routine de veille.
